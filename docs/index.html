Teste o Schema Markup do seu localhost

Com o validador rodando no seu computador, abra o painel, digite localhost:3000/99pay e marque Incluir subpáginas para analisar as rotas filhas.

Abrir validador local

Primeiro acesso

Com Git e Node.js 22 ou superior instalados, execute os comandos abaixo e mantenha o terminal aberto.

git clone https://github.com/lucas-amaral01/validador-local-schema-markup.git
cd validador-local-schema-markup
npm ci
npm run dev

Inicie também o projeto que deseja testar na porta dele. Nas próximas vezes, basta executar npm run dev na pasta do validador.
